系统设置

检测参数与接口配置
检测设置
0.25
阈值越高越严格：低于该置信度的检测框与告警将被忽略。一般现场建议 0.25 ~ 0.45。
接口配置 对接 Python 检测服务
· 默认连接本地检测服务 http://127.0.0.1:8765（运行 scripts\\detect_server.py 启动）。
· 图片 / 视频 / 摄像头画面会按周期发送到检测接口，检测框、置信度和违规类别均使用真实模型输出。
· 请求格式：POST JSON {"image":"data:image/jpeg;base64,...","threshold":0.25,"source":"camera"}。
· 返回格式：{"detections":[{"class":"no_helmet","confidence":0.93,"bbox":[x,y,w,h]}]}，bbox 默认像素坐标，也支持 normalized:true 或 bbox_format:"xyxy"。
· 类别名支持 no_helmet / no_vest / climb 等英文或「未戴安全帽 / 未穿反光衣 / 翻越护栏」中文。
· 页面始终使用真实模型输出；接口不可用时停止请求，重新开始检测或保存配置后再重试。
